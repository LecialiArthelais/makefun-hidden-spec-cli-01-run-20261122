mend is one patch tool for every AI edit format. It applies an AI-written edit to a tree of text files in any of the four formats models write — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON tool-call edits — matching lines at three tiers of whitespace tolerance, and writing every file or nothing at all. See `SPEC.md` for the full specification.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
